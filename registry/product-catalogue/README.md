# Product Catalogue

This directory will hold user-selectable product/program records. It is intentionally separate from `registry/planning/source-families.v0.5/`.

## Source family vs product

- Source family = monitoring/authority unit, e.g. `card.smbc`.
- Product = concrete user-selectable item, e.g. a specific current SMBC card SKU.

Do not create product records by extrapolating from issuer-family names. Enumerate products from canonical issuer/program sources.
